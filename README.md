### 🐾 PawPals — Pet Adoption & Management Platform

**MERN Stack · React · Node.js · Express.js · MongoDB**

A pet adoption and management web application designed to connect people who want to adopt pets with pet owners who want to put their pets up for adoption.

**Key Features**

* 🐶 Browse available pets and view detailed information
* 👤 User registration and login
* 🔐 JWT-based authentication
* 🏠 Submit pets for adoption
* 📩 Submit and manage adoption requests
* 🛡️ Admin dashboard for managing pets and adoption requests
* ✅ Admin approval/rejection workflow
* 🗄️ MongoDB database integration
* 🔒 Password hashing using bcrypt
